# Socrates

The AI Apprentice (Hack-Nation × ElevenLabs, Challenge 01). Socrates watches how experts actually work, asks *why* at natural pauses, and turns what it learns into short, interactive Work Maps for the next generation.

| Folder   | What                                               | Owner |
| -------- | -------------------------------------------------- | ----- |
| `web/`   | Webapp: Work Maps, Ask, Capture ([README](web/README.md)) |       |
| _`extension/`_ | Browser extension: screen, mic, keystrokes (to come) |       |
| _`server/`_    | Backend: vision events, Work Map generation, Q&A (to come) |       |

The data contract between all three lives in [`web/src/lib/api/types.ts`](web/src/lib/api/types.ts).
