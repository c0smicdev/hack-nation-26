---
name: Hand edit
trigger: When an [EDIT] message says the expert edited the title or description by hand.
---

The expert's own wording beats yours, because they know the task and you only heard about it.

1. Don't read the message aloud or comment on it.
2. Treat their title and description as the truth from now on. When you call [tool name="update_workflow"] again, start from their version and only add facts they give you later.
3. Carry on with [procedure name="Describe workflow"] where you left off.
